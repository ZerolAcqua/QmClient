# 聊天记录导出

## 确认范围

- 本次仅优化本地控制台“选择导出”生成的聊天 HTML / PNG；原有 TXT 同步导出入口保留。
- HTML 与 PNG 采用相同的深色聊天布局：圆形头像、气泡上方昵称、气泡内正文、气泡外弱化时间；自己的消息靠右，其他消息靠左。
- 玩家消息使用发言时的真实 Tee 皮肤及配色快照。皮肤缺失或旧记录没有快照时，按发送者名称生成稳定的随机配色 Tee，同一发送者的回退头像保持一致。
- 保留控制台既有消息合并行为；多人合并行无法对应单个玩家皮肤时使用回退头像。真实皮肤头像使用正常站姿与普通眼睛，0.7 皮肤保留身体、脚、标记和装饰，不包含临时帽子或机器人叠加。
- 不涉及游戏截图、demo、协议、物理、预测或皮肤文件格式。用户尚未提供无响应的消息数量与准确触发时机，因此验收覆盖准备和导出两个阶段。

## 实现约定

1. 聊天记录写入控制台时，一并保存发送者、正文、本地玩家标记与不可变头像快照。导出时不根据当前在线玩家列表反查历史皮肤，避免玩家改名、离开或换皮肤后历史头像变化。
2. 点击导出后冻结所选记录。主线程只分帧准备字形，每帧以 2 ms 和最多 32 个字形为预算；字形数据准备完毕后提交后台任务。
3. 后台任务只读取已准备的字形和头像数据，完成文本排版、头像合成、PNG 分页与 TXT / HTML / PNG 保存。后台任务不调用字体或图形渲染接口。
4. PNG 宽度为 1080 像素，每页高度不超过 12000 像素；超过一页的消息按正文行继续到下一页，避免截断聊天内容。HTML 内嵌头像，离线打开即可查看。
5. 同一时间只允许一个导出任务。准备时显示百分比，导出图片时显示已完成页数；支持取消，任务结束后恢复可操作状态。
6. 版本在工作区已有 `3.6.4` 基础上更新为 `3.6.5`。

## 验收清单

- 少量、多量、单条超长及混合中英文消息均可导出，顺序和正文完整；多页 PNG 不遗漏跨页内容。
- HTML 与 PNG 均显示圆形 Tee 头像、昵称、正文气泡和弱化时间；自己的消息靠右，其他消息靠左。
- 发言后换皮肤、离开服务器再导出，历史记录仍使用发言时快照；无快照消息的同名发送者保持同一回退头像。
- 字形准备与图片保存期间客户端仍可处理输入；重复点击导出不启动第二个任务；准备阶段和导出阶段均可取消。
- 中文、换行、HTML 特殊字符和长昵称正常显示；HTML 特殊字符转义后作为文本呈现。
- 按用户要求，仅补全测试代码，不进行编译或运行测试；源码卫生门禁使用 `python qmclient_scripts/gate/check_gate.py --mode quick`。
