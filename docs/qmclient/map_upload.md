# 公用测图服地图上传

## 已确认范围

- 在 Qm 功能页增加独立的“地图上传”卡片，显示所选文件、自动取得的玩家名、上传状态和使用说明。
- 每次选择一个已保存的 `.map` 文件，入口提供 `maps` 和 `downloadedmaps` 目录；编辑器中尚未保存的改动需要先保存。
- 在线时使用当前控制角色在服务器中的名字，离线时使用主玩家配置名。点击上传时取得名字并作为 `player_id` 发送，不新增名字输入框。
- 用户已确认允许客户端内置公开使用的 token；文档和上传状态不重复显示 token。
- 点击上传才发起请求；同一时间只执行一个上传，异步显示状态，允许取消。失败后由玩家手动重试，不自动重试、连接服务器或发送换图命令。

## 文件与接口约定

- 地址：`POST https://shengyan.art/api/upload`。
- 鉴权：`Authorization: Bearer <token>`。
- 请求体：`multipart/form-data`，包含文件字段 `file` 和玩家名字段 `player_id`。
- 客户端限制文件大小不超过 64 MiB；这是客户端实现限制，尚未确认服务端限制。
- 扩展名 `.map` 不区分大小写。文件全名只能有扩展名前的一个点，去掉扩展名后的名称不能为空，也不能以空格或点结尾。
- 按官网上传页规则拒绝文件名中的 `!@#$%^&*()+|\/[]{};:'",<>=`，并拒绝 multipart 文件名中的控制字符。中文、英文字母、数字、名称中间的空格、下划线及短横线均可使用；此处不是字符白名单。
- 上传前检查文件、文件名、大小及玩家名；文件读取、multipart 组装和请求正文复制由后台任务完成。仅 HTTP 2xx 且 JSON 布尔字段 `success` 为 `true` 时显示成功；传输失败、服务端拒绝和无法识别的响应分别反馈。
- 取消只中止客户端请求；服务器若已收完文件，取消不会撤销已完成的上传。同名文件是否覆盖以服务端行为为准。

## 卡片使用说明

1. 上传 `.map` 文件到公用测图服；服务器密码和管理密码均为 `s`。
2. 进入服务器后按 F2，用管理密码登录，输入 `change_map 地图名` 换图。
3. 再次上传地图后，输入 `reload` 或 `hot_reload` 更新地图。

## 接口调查记录

2026-09-17 对 [服务官网](https://shengyan.art/) 与用户指定接口的调查：

- 官网页面 JavaScript 使用 `/api/web-upload`；客户端依用户要求使用 `/api/upload`，没有擅自替换为网页专用入口。
- 不带鉴权的接口请求返回 HTTP 401，JSON 包含 `success: false` 和 `message`。
- 带 token 但未提交文件的请求返回 HTTP 500，JSON 包含 `success: false` 和与 `latin-1` 编码异常有关的 `message`。这说明接口当前有服务端错误路径，不能据此推断正常上传响应。
