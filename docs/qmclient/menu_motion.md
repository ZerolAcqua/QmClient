# 菜单交互动效

## 已确认范围

2026-09-14，用户确认主页、服务器列表、新版设置页及弹窗参考苹果原生交互；目前没有具体掉帧复现，同时要求兼顾性能。以 macOS 桌面交互为主要参考，保留现有布局、功能和输入语义。

## 实现约束

- 短促、克制的反馈；按钮文字保持稳定，导航与开关小幅弹性，连续操作接续当前运动。
- 沿用现有 QmUi 动画运行时、解析弹簧和目标缓存。控件静止时不反复提交动画，滚动不改变开关的逻辑动画目标。
- 不新增模糊、离屏渲染、整页缩放、列表逐行入场或第三方依赖；保留现有设置页文字缓存、裁剪及预算调度。
- 遵守关闭／减弱／完整动效选项，交互不等待动画结束。

## 参考

- [Apple Motion](https://developer.apple.com/design/human-interface-guidelines/motion)：短促准确、允许打断、避免频繁交互中不必要的运动。
- [SmoothUI](https://smoothui.dev/docs/components/animated-tabs)：连续的选中指示器反馈。
- [Motion](https://motion.dev/docs/animate)：动画与手势速度接续。

参数是结合 QmClient 的 C++ UI 适配，并非苹果系统内部动画参数。

## 完成的行为

- 共享菜单悬浮反馈 120ms、按压反馈 80ms，颜色先响应、平稳结束。按钮不移动文字，旧菜单按钮减少一层悬浮叠加绘制；设置标签的字号、宽度和位置保持稳定。
- 主导航与分段导航共用小幅弹性参数。开关使用 0–1 相对进度，初次显示直接采用配置值，滚动与控件布局位置变化不再启动开关动画。静止帧不重复提交完成事件，关闭动效会停止正在进行的弹簧。
- 主菜单、游戏内菜单、服务器分类及筛选分类连续切换时保留当前进度；当前入场阶段保持所在方向，避免反向点击使内容跳到另一侧。大面积过渡限制在 8 UI 单位以内，减弱动效时取消该位移。
- 普通菜单弹窗与弹出菜单只做 85%–100% 的背景表面过渡，正文立即显示且可操作，不缩放或重新排列正文。刷新已存在的弹出菜单不会重新入场。
- 通用 Modal 修复动画结束后重复播放问题，完整入场采用 0.98–1 的缩放；退出途中重开保持连续。减弱／关闭动效时 Modal 和 Toast 停止几何动画。
