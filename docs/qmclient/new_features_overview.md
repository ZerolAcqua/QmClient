# QmClient 新功能速递

Demo 剪辑更顺手，旁观可以直接查找 CP，还带来了双人存档恢复、DDRace 地图进度、新拖尾和皮肤描边。

> 以下为 3.6.1 源码对应的更新内容，使用新功能需要更新客户端；收到广播不会自动安装更新。

---

## Demo 剪辑与回放

- **快速选片段**：播放 Demo 时按 `I` 设置起点、`O` 设置终点，右键对应按钮可清除标记。
- **区间预览**：按 `P` 从选区起点播放，到终点自动暂停，再按一次停止预览。快捷键需在播放器中开启。
- **多段导出**：用 `+` 添加片段，列表支持滚动、单段预览与删除。导出默认使用 `_cut` 新名称，时间显示精确到百分之一秒。
- **独立显示设置**：“Demo 显示”可调整方向键、强弱钩及其范围，并单独开关 HUD 和聊天。预览与视频共用设置，不影响正常游戏。
- **播放器布局更新**：标题、时间轴和剪辑操作分层显示。保留移除聊天选项；视频导出需要客户端包含视频录制支持。

## 旁观直接查找 CP

打开旁观选择面板，在底部输入 **1–255** 的传送编号，按回车或点击“查找／下一个”，镜头即可切到对应位置。

- 在线旁观和 Demo 旁观都可使用，按住默认右 Shift 也能直接输入数字。
- 同编号有多个位置时可重复查找；覆盖普通传送入口、出口、CP 和 CTO。
- 找到后切为自由视角；没有匹配时保留当前镜头。这里查找的是传送编号，不是计时 CP 序号。

## 本地双人存档恢复

进入地图后，客户端会提示本地保存的同地图双人存档。记录来自 `ddnet-saves.txt`，需包含可识别的完整队员名字。

- 输入 `/qm Yes` 恢复最新一条，或 `/qm Yes 序号` 选择其他记录。
- 确认后自动准备本体与分身名字、连接分身、组队并读档；只使用空队或仅含本体与分身的队伍。
- 输入 `/qm No` 取消，忽略提示不会自动操作。断线、换图或超时会停止后续步骤，已改的名字和队伍不会自动还原。
- **确认读档成功后才清理对应本地记录**，失败或无法确认时保留。自动恢复和手动 `/load` 均适用。

## DDRace 地图进度

地图进度条现在支持 **DDRace 位置估算**，沿用原来的底部进度条和 HUD 样式。

- 向前推进时上涨，回头接人时可以下降；主号与分身分别计算。
- 支持计时 CP、普通传送和 CP 回传；没有合适分段时使用全图估算。
- 这是位置参考，不代表耗时或难度；复杂机关与协作路线可能有偏差，尚未算出有效路线时显示未知。

[[settings:qm:player_stats|打开地图进度设置]]

## 新拖尾与皮肤描边

### 五种拖尾风格重做

- **黑闪**：近黑主体与猩红裂纹。
- **Exo 高能科技**：青蓝能量束、近白核心与洋红侧轨。
- **灵光**：青白柔边、摆动细丝与漂浮光点。
- **虚空**：液态黑影与淡化断层。
- **冥火**：炭黑、深红、金橙火焰，带火舌与余烬。

保留原版拖尾与原样式编号。关闭样式配色后，仍可使用纯色、Tee 颜色、彩虹、速度或随机颜色。轨迹按移动距离采样，停下后自然消散，Demo 暂停时冻结、跳转时清理旧轨迹。

[[settings:tclient:tee-trails|打开拖尾设置]]

### 可调皮肤外描边

自己和分身、其他玩家可分别开启描边，支持颜色、粗细和透明度调整，默认关闭。

描边保留皮肤原图案与黑边，跟随角色缩放、变形和换肤过渡，支持 0.6／0.7 角色。手、武器和钩子不参与描边。

[[settings:qm:skin_transition|打开皮肤描边设置]]

## 昵称与头顶指示器

- **昵称六档范围**：关闭、当前角色、本体与分身、其他玩家、其他玩家加未操控的本地角色、全体。
- **方向键与强弱钩独立调整**：开关、大小和拖动位置各自控制，关闭或放大其中一项不再推移另一项，设置预览保持稳定。
- **范围按钮统一样式**：新版界面在宽度足够时使用圆角分段按钮，窄窗口保留紧凑布局。

[[settings:deck:appearance-name-plate-settings|打开昵称设置]]

## 资源编辑器调色升级

每个部件都能独立设置颜色、混合模式和 **0–100% 强度**，预览与导出效果共用同一处理方式。

支持 16 种模式：正常、变暗、正片叠底、颜色加深、变亮、滤色、颜色减淡、叠加、柔光、强光、差值、排除、色相、饱和度、颜色、明度。

选中部件后在顶部调整，拖入素材会保留目标部件的调色设置。右键重置或“重置全部”恢复默认；设置只保留在当前编辑会话，切换主素材或资源类别会重置部件。

## 实时同步与协作

在线识别、称号、开发者标记、远程粒子与语音在线状态、游玩时长、服务器时间和广播，统一改用 **WebSocket 实时同步**。

- 默认开启，断线后自动重连并重新同步；不再通过 HTTP 定时轮询，关闭 `qm_websocket` 会停止这些后台同步。
- 编辑器协作改为主动推送地图快照，保留四人房间和原操作方式；重连后重新加入房间，未确认上传不会自动重放。
- 语音音频继续使用 UDP，下载及赞助码兑换等主动操作沿用原方式。

## 菜单与性能改进

- **交互更连贯**：菜单、服务器列表、开关和弹窗采用短促反馈，快速切换接续当前动画；保留关闭和减弱动效选项。
- **设置页文字缓存改进**：关闭预热时也能建立可见文字缓存，减少反复绘制与切页跳动。
- **减少主线程工作**：图片表情解码、聊天日志写入、音乐进程检测、歌词读取和积分解析移入后台处理。
- **减少重复计算**：优化拖尾、地图轮廓、粒子、HUD、状态栏和资源队列，并调整相邻绘制命令合并与 Vulkan 任务分配。

实际帧率收益取决于地图、设置和设备，本次没有统一的提升百分比。

### 一键性能诊断

在“QmClient → HUD → 调试模式”开启，或输入 `qm_perf_debug 1` 开始记录，输入 `qm_perf_debug 0` 结束。

自动采集帧时间、卡顿和配置变化，分析报告支持搜索配置并查看前后变化；密码、Token 等敏感值写入前脱敏。遇到卡顿时可用来记录复现过程。

[[settings:qm:debug_mode|打开性能诊断设置]]

## 其他改进

- **头衔颜色生效更一致**：单色和彩虹优先于风格自带渐变，保留浮动与掠光；跟随服务器模式保持原规则。失败刷新不再立即清空已知样式，减少闪变。
- **主动断开入口调整**：按键绑定移到“设置 → 控制 → 杂项”，原绑定继续有效，没有新增默认快捷键。
- **配套界面文案更新**：补充相关多语言条目。
