# 新功能

这个弹窗现在是**中心服广播**了：以后新功能直接推到这里，不用等下一次客户端更新。

---

## 本次更新亮点

### 输入覆盖层重做

- 位置改为**按屏幕百分比**定位，窗口大小、分辨率怎么变都不会再跑偏。
- 键盘和鼠标**各自独立缩放**，把鼠标放大也不会顺手撑大键盘。
- 现在放在 **设置 → HUD → Input overlay**，对应「Horizontal position / Vertical position / Mouse size」。

### 头衔配色可以自己调

- 支持**跟随服务器 / 单色 / 彩虹**三种模式，还能单独调透明度，铭牌和聊天共用同一套颜色。
- 现在放在 **设置 → QmClient → Contributors**（「Fallback title color」）。

### 控制台日志分类筛选

- 本地控制台顶栏新增 **All / Player / System / Command / Binds** 分类按钮，点一下只看想看的那一类。
- 选择会跨启动保留，默认全亮。

### 铭牌渲染回到引擎文本链路

- 移除了铭牌专用的 MSDF 图集与渲染器（顺手省掉一个 12MB 的 CJK 图集）。
- 文字现在按真实屏幕像素密度栅格化，缩放不再糊，改字号/配色即时生效。

---

## 顺带一提

- **DDRace HUD Pro**：新增分身卡键 / 锤子 / 控制 / 复制状态显示，可在 HUD 卡片里逐项开关。
- **歌词来源扩展**：网易云音乐、汽水音乐、Spotify 三家 Hook，在设置里三选一即可（Spotify 需要填一次 `sp_dc`，抓不到歌词会自动回退 LRCLIB）。
- **设置页**：卡片可拖拽排序、全局搜索定位、卡片展开/重排动画，整体手感重做过一轮。
- **自动更新**：稳定版可自动检查并在退出时安装。
- 屏幕缩放不再额外做线性插值，与 DDNet 原版手感一致。
