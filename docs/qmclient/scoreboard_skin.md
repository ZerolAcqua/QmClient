# 计分板复制皮肤

## 已确认行为

- 按住 TAB 打开计分板，启用计分板光标，点击玩家后，在已有加好友等操作中增加一个复制皮肤图标。
- 在 0.6 服务器悬停图标时显示目标玩家的皮肤名称，点击立即将其应用到当前控制的主号或 dummy，只修改该角色。
- 复制服务器报告的皮肤名称、自定义配色开关及身体和脚颜色；目标使用原色时，关闭自己的自定义配色。客户端强制皮肤、冻结外观、强制颜色等渲染效果不作为复制来源。
- 使用现有皮肤配置与信息发送流程，配置随客户端正常保存保留，重新进入游戏后仍使用所选皮肤。
- 0.7 服务器禁用该图标，悬停说明仅支持复制 0.6 皮肤；点击不修改主号或 dummy 的配置。

## 手动验收

1. 主号连接 0.6 服务器，选一名使用自定义配色的玩家。通过计分板玩家菜单悬停图标核对名称，点击后检查主号皮肤、身体和脚颜色；dummy 的配置应保持原值。
2. 切换控制 dummy，再复制另一名玩家的皮肤。检查仅 dummy 改变，主号保持上一步的配置。
3. 选择使用原色的玩家，复制到当前角色，检查自定义配色已关闭。启用客户端强制皮肤或强制颜色后重复操作，确认复制的仍是目标服务器皮肤信息。
4. 连接 0.7 服务器，检查图标禁用、悬停提示正确，点击后主号与 dummy 的皮肤配置均不改变。
5. 在 0.6 服务器分别为主号和 dummy 完成复制后，正常退出客户端并重新打开、进入服务器，确认各自皮肤名称与配色保留。

上述步骤为待执行的手动验收清单，不代表已通过。按本次约定不进行编译或测试运行。
