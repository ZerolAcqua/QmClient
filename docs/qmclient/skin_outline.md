# 皮肤描边

## 行为

- 设置入口：QmClient → 视觉 → 皮肤切换 → Tee 外观，搜索“皮肤描边”也可定位。
- `qm_skin_outline_local`：自己和分身；`qm_skin_outline_others`：其他玩家。两个开关默认均关闭。
- `qm_skin_outline_color`：描边颜色，默认青色；`qm_skin_outline_width`：粗细 1～6，默认 2；`qm_skin_outline_alpha`：不透明度 0～100，默认 100。
- 粗细以标准大小角色的游戏坐标为基准，跟随角色缩放和果冻变形。
- 对 0.6 身体、双脚和 0.7 身体、装饰、双脚生效，保留原皮肤图案与既有黑边；手、武器、钩子不参与。
- 换肤过渡两侧分别使用对应皮肤描边；冻结外观、白脚与小 Tee 使用实际绘制的形状。描边不透明度乘以角色不透明度。
- 局内角色及玩家残影生效，普通菜单预览、未预测阴影和分身小地图不新增描边。

## 实现

`src/game/client/components/qmclient/qm_skin_outline.h` 合并填充与原有轮廓的透明度，按圆盘膨胀并减去原始遮罩，得到可染色的外侧环带。遮罩最长边最多 128 像素，普通 96 像素皮肤保留原始采样；低分辨率素材补足到每游戏单位至少一个采样点，避免细描边消失。

各皮肤持有遮罩并与渲染快照共享；首次启用或粗细变化时生成纹理，颜色、透明度和动作变化复用纹理。皮肤卸载时释放纹理并清空遮罩，旧快照不会重新上传失效素材。CPU 膨胀采用逐圆盘截面的滑动最大值；普通 0.6 角色每次渲染增加三个四边形。
