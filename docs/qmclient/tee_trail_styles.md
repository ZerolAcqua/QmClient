# Tee 拖尾系统（TClient / QmClient 3.4.0）

## 范围与行为

在既有 `CTrails`、Tee Trails 菜单和 `tc_tee_trail_*` 配置上重构。五种风格共用轨迹状态和网格绘制，原版入口也使用同一采样器与单层色带。保留其他脚底粒子逻辑。没有修改物理、预测、协议、碰撞或 Graphics Backend，没有增加 Shader。

配置编号保持历史对应关系，避免旧配置中的灵光与虚空换位：

| 编号 | 名称 | 形状与分层 |
| --- | --- | --- |
| 0 | Original / 原版 | 单层色带；保留颜色模式、宽度、淡出和收尖开关 |
| 1 | Black Flash / 黑闪 | 近黑 Outer/Main 实体，固定弧长噪声制造锐利非对称撕口；两道断续猩红裂纹使用加法混合，速度提高时裂纹更强。没有火焰上浮或蓝色能量圈 |
| 2 | Exo / 高能科技 | 较窄、稳定的青蓝能量束、近白核心与洋红侧轨，扰动极低；发光层使用加法混合 |
| 3 | Spirit / 灵光 | 青白、淡蓝柔边色带与错相细丝，明显的平滑 S 型摆动，缓慢上浮；寿命最长，最多四个漂浮光点 |
| 4 | Void / 虚空 | 接近纯黑的液态阴影，两侧缓慢起伏、局部淡化断层；极低透明度冷灰细边，全部普通混合，保持吞噬感 |
| 5 | Inferno / 冥火 | 炭黑外层、深红主体、金橙核心，按年龄冷却到暗红；旧轨迹轻微上浮翻卷，最多四处细火舌和四颗余烬 |

原咒焰升级为黑闪、紫电升级为 Exo、黄金升级为冥火。默认开关与默认样式值不变。样式配色关闭后按纯色 / Tee 颜色 / 彩虹 / 速度 / 确定性随机颜色派生，几何保持一致。新样式始终具有生命周期淡出和尾端收尖；旧 Fade 开关额外增加沿长度的淡出，Taper 开关控制原版宽度收尖。宽度为零时原版使用像素细线，新样式使用 4 单位基准半宽。

## 统一架构

1. `CTrails` 在现有 players 组件之前执行，从角色最终 `m_RenderPos` 采样一次。每个玩家含一个 `CTrailState`；prediction ghost、race ghost 和 dummy 小地图绘制不会重复采样。主号与 dummy 都视为本地玩家。
2. `CTrailState` 使用 192 点固定环形队列，加一个临时渲染头。每移动 6 个世界单位保存一个点，累积不足部分跨帧保留；高速帧内按距离补点，并插值出生时间和速度。位置、速度来自既有渲染结果，不回写预测世界。
3. 时间与累计弧长采用 double。低于 0.15 世界单位/tick 时停止生成；停下后不刷新最后移动点的出生时间。寿命受原长度设置、风格和速度影响，默认长度 25 对应约半秒，Spirit 为 1.45 倍基础寿命。
4. `BuildEffect` 是不依赖 Graphics 的几何构建器。局部切向受限的三次曲线处理转弯，避免折返过冲；根据屏幕像素尺寸细分，最多 384 截面。共享宽度/透明度包络使尾部自然收尖，曲率约束防止宽截面在急弯处自交。
5. 每个截面只计算一次风格扰动，然后生成 Outer、Main、Core、Accent 四层。全部使用同一个三条横向渐变带绘制器，逐顶点透明度形成羽化边缘；曲线和细节使用连续相位，不能先取模再乘非整数谐波。
6. 随机细节绑定客户端种子与累计弧长，不依赖帧号、当前数组索引或 `rand()`。黑闪的裂纹随机形状在节点生命周期内固定；年龄只控制整体消散与收窄。
7. CPU 输出和 Graphics 提交使用同一个周界顶点顺序；颜色底边按 `SetColor4(P0, P1, P3, P2)` 配对。普通/加法混合切换先结束批次。绘制退出时恢复白色、零旋转、完整纹理子集和普通混合。

## 生命周期与不连续移动

- 关闭功能、离线、缺失游戏快照、样式/长度/主 dummy 切换均清空状态。
- 快照入口清除失活与死亡玩家，涵盖两帧渲染之间的死亡再出生。
- Demo 进度条、按时间跳转与逐 tick 跳转显式调用 `OnReset`；暂停时游戏时间不推进，旧轨迹冻结。
- 时间回退、超过 12.5 tick 的观测间隔、超出速度预算的位置跳变清空队列。
- 额外检查服务端和渲染端前后端点的位移，屏蔽传送插值窗口，防止跨屏直线逐帧被采样；Ninja 的移动预算包含冲刺速度。
- 此处没有新增传送协议事件。距离很短且位移落在速度容差内的传送无法与正常移动完全区分，但不会生成跨屏长线。

## 性能边界

- 每玩家 192 个历史节点，导出最多 193 个点，网格最多 384 个截面、4704 个四边形。
- 输出 vector 由组件持有并复用；每帧几何运算使用固定容量数组，无按风格分配的临时 vector。
- 不可见时仍维护状态，但按整条轨迹包围盒跳过几何构建；头部出屏不会立刻截掉可见尾部。
- 原配置长度会受到历史容量上限限制，极长高速轨迹不会无限增长；极端放大也受截面预算限制。
