# Tee 拖尾样式（TClient）

本文说明 TClient「Tee Trails」卡片新增的 5 套拖尾特效：形态、运动、消散、配色来源，以及实现与配置入口。

5 套样式**不是同一骨架换五种配色**，而是各自一套独立的几何语言与运动方式；配色只是各自的标志性色，把「使用样式专属配色」关掉后形态完全不变（`QmTeeTrailStyles.StylesAreStructurallyDifferentNotPaletteSwaps` 用与配色无关的空间指纹锁住这一点）。

## 行为约定

- 拖尾只描述「Tee 已经走过的轨迹」，因此**移动时生成、停下后自然消散**，不产生任何玩法效果。
- 爆发、闪烁、翻卷都属于**视觉动画**，只依赖时间与轨迹几何，不影响物理、预测或输入。
- 宽度、长度、透明度、显示他人拖尾这些既有设置对新样式同样生效：
  - 宽度经 `CTrailPart::m_Width` 进入每套样式的分层宽度；
  - 长度决定轨迹采样窗口；
  - 透明度（含他人队伍透明度）作为整体上限，所有四边形都不会超过它；
  - `显示他人拖尾` 关闭时只为本地玩家绘制。
- 新样式默认使用各自的标志性配色；取消勾选「使用样式专属配色」后，改用原有颜色模式（纯色 / Tee 颜色 / 彩虹 / 速度 / 随机）派生配色。
- 非法配置值（越界、历史残留）统一回落到原版拖尾。

## 5 套样式

| 配置值 | 名称 | 灵感来源 | 视觉表现 |
|--------|------|----------|----------|
| 0 | Original（原版） | DDNet / TClient 既有拖尾 | 保持原有单色带渲染，不受本模块影响 |
| 1 | Cursed Flame / 咒焰·黑闪 | 《咒术回战》黑闪与咒力外放 | **横向扇开的翻卷火舌**：三股火舌向同侧扇出、越靠尾端张角越大并随年龄上浮翻卷；中轴压一条近黑核心、外缘镶猩红描边，再甩出黑芯猩红分叉电弧；Tee 所在处爆开雷环与放射尖刺，短促爆发后碎裂成上飘火星。能量只铺在身后一小段（`Reach` 0.55），是五套里最短促的一套 |
| 2 | Violet Lightning / 紫电·雷切 | 《鬼灭之刃》雷之呼吸·柒之型「火雷神」（紫色版） | **一太刀决断的斩击**：一道横跨轨迹的薄斩线沿轨迹推进，身后留下正在淡出的刀痕；另有贯穿全条的一道路径主雷、从轨迹甩向两侧的乱枝折线闪电、落点雷环与雷棘、溅射电火花。原本的金黄雷炎整体改成紫色，全部落在紫 → 近白紫区间，靠雷纹的硬折角与通断表现「雷」 |
| 3 | Spirit Light / 灵光·流萤 | 《奥日与萤火意志》 | **柔软编织的流光细丝**：三股同频同幅、相位差 120° 的细丝在轨迹上反复交叉成编织状，叠断续光缕与一条中心亮丝；沿线交叠若干呼吸中的圆形柔光光团，尾端散成缓慢外扩上升、逐渐变淡的光点。整体最柔、最慢，光点是主角而不是点缀 |
| 4 | Void Shadow / 虚空·暗影 | 《空洞骑士》虚空 | **墨黑实体的负空间造型**：头部厚、尾部散的墨黑烟身与两股向外卷曲再收回的触须，用灰白薄边勾出轮廓，另有一层向两侧扩散、越靠尾端越碎的墨雾；尾部向中心收缩并崩成碎片。五套里唯一的「暗主体 + 亮描边」 |
| 5 | Golden Grace / 黄金·赐福 | 《艾尔登法环》赐福指引 | **编织流动的金色丝线**：三道金丝用不同频率、不同流动方向交织成辫，若干位置有横向交织细弧把最外侧两股连起来；沿线每隔一段亮起一颗呼吸的赐福脉冲，金尘随年龄缓缓上升飘散。是「线」而不是「带」，节奏最慢、衰减最缓 |

## 分层与观感

模块提供一组共享的几何原语，但**每套样式用哪些原语、怎么摆、怎么动是自己决定的**：

| 原语 | 作用 | 主要用在 |
|------|------|----------|
| `EmitStrand` / `EmitBrokenStrand` | 沿轨迹的带子（可逐点扰动宽度、透明度、位移），可用时间相位错开通断 | 五套的柔光与主体 |
| `EmitBar` | 横跨轨迹宽度的一道薄条（端点最亮、纵向两端衰减） | 斩线、赐福脉冲 |
| `EmitRing` | 以一点为圆心的环带 | 爆裂环、落点雷环、光团、赐福脉冲 |
| `EmitSpike` | 从一点向外的细长尖刺 | 黑闪的放射爆闪 |
| `EmitLightningPath` | 从一点甩出的多段折断折线 | 紫电的乱枝、雷棘 |
| `EmitArc` | 三段定长分叉电弧（黑芯 + 亮边） | 黑闪的分叉电弧 |
| `EmitDot` / `EmitStreak` | 旋转小方块 / 细长亮条 | 光点、金尘、碎片、电火花、火星 |

层次仍遵循「铺底 → 主体 → 核心 → 装饰」的顺序（先画的在下），但各套的分层含义不同：

- 黑闪：柔光铺底 → 扇开火舌 → 猩红描边（先画）→ 黑色核心（后画，只留一条暗红边）→ 头部爆裂 → 分叉电弧 → 飞散火星；
- 紫电：柔光铺底 → 刀身细丝 → 斩线与刀痕 → 路径主雷 → 乱枝紫电 → 落点雷环与雷棘 → 溅射火花；
- 流萤：一层淡柔光 → 三股编织细丝 → 断续光缕与中心亮丝 → 柔光光团 → 漂浮光点；
- 暗影：扩散墨雾 → 墨黑触须（头部厚、尾部薄）→ 灰白薄边 → 悬浮碎片（暗芯 + 亮边两层）；
- 赐福：金色辉光 → 三道编织金丝 → 交织细弧 → 赐福脉冲 → 飘散金尘。

### 上浮（buoyancy）

火焰、墨雾、流光、金尘都按年龄在世界坐标里向上飘（年龄越大飘得越高，并带轻微横向摆动）。
水平跑动的 Tee 如果只把各层贴在中轴上，画面就是几条平行色带——上浮是这些样式「像火 / 像烟」的关键。
紫电不用上浮：它靠斩线沿轨迹推进、以及主雷随时间流动来表达动能。

### 采样与长度

拖尾采样间距按整条拖尾长度自适应（只保底 1.5px，不封顶），最长 48 个采样点覆盖**整条**轨迹；
末端 30% 弧长做透明度软收，避免采样窗口走完时整条被硬生生截断。
`Reach` 决定特效沿轨迹铺多远：黑闪 0.55（只在身后一小段炸开），其余接近贯穿全条。

## 消散

- 每套样式有独立寿命（tick）：黑闪 28、雷切 20、流萤 42、暗影 36、赐福 45（50 tick = 1 秒）。
- 年龄取自采样点 tick 与当前 tick 的差，透明度按寿命单调衰减，超出寿命的采样点不再产生几何。
- 因此 Tee 停下后：尾迹先按年龄淡出，再随拖尾历史窗口一起消失，不会出现整条突然消失的跳变。
- 原地不动（总位移过小）、整条不可见（透明度为 0）、轨迹出现传送级跳变时都不生成几何。

## 代码入口

| 位置 | 作用 |
|------|------|
| `src/game/client/components/tclient/qm_tee_trail.h` | 样式枚举、`SQuad`、`BuildEffect` / `ResolveStyle` 声明 |
| `src/game/client/components/tclient/qm_tee_trail.cpp` | 采样重采样、分层几何、配色与寿命表 |
| `src/game/client/components/tclient/trails.cpp` | 选择原版路径或新样式路径并绘制四边形 |
| `src/game/client/components/tclient/menus_tclient.cpp` | Tee Trails 卡片的样式下拉与配色开关 |
| `src/engine/shared/config_variables_tclient.h` | `tc_tee_trail_style`、`tc_tee_trail_style_colors` |

`BuildEffect` 是纯函数式接口：输入拖尾采样、样式、是否使用样式配色、当前时间、宽度与随机种子，输出四边形数组。渲染端只负责把四边形画出来，因此特效逻辑可以单元测试（见 `src/test/qmclient_monitoring_test.cpp` 的 `QmTeeTrailStyles.*`）。

## 配置项

| 配置 | 默认 | 范围 | 说明 |
|------|------|------|------|
| `tc_tee_trail_style` | 0 | 0–5 | 拖尾样式，0 为原版 |
| `tc_tee_trail_style_colors` | 1 | 0–1 | 使用样式自带配色；关闭后改用拖尾颜色模式 |
