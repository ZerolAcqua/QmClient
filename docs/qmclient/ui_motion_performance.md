# UI 与 HUD 动效连续性优化

## 已确认范围（2026-09-17）

用户反馈为 UI 移动和游戏内组件动画观感不够顺滑，没有指定偶发卡顿复现。允许优化客户端及引擎热点，保持协议、玩法、物理和预测行为。确认菜单、滚动及 HUD 连续接续当前速度，运动保留小数坐标，短暂卡顿按真实经过时间推进，过期动画恢复前台后完成；保留关闭、减弱动效设置。

灵动岛采用紧凑方案：默认 1080p 主体高度由约 46px 调至约 40px，其他分辨率同比缩放，保留现有宽度适应、展开内容、歌词、计时、状态、配色以及 HUD 编辑器缩放。参考苹果的紧凑/展开呈现思路，数值是本项目适配值，不是苹果官方像素尺寸。参考：https://developer.apple.com/videos/play/wwdc2023/10194/

按用户要求只补测试代码并运行 quick 源码门禁，不编译、不执行测试、不启动客户端。当前工作树已有大量其他改动，本任务只增量修改相关路径。

## 调查证据

- 公共 UI 运行时与动画轨道把每帧经过时间截到 1/15 秒，长帧后动画会比实际时间落后；弹簧已经采用解析解。
- 原生滚轮每次输入重新启动三次缓动，没有继承当前速度；连续滚动和反向输入会改变瞬时速度。
- 设置卡片每帧将四边取整到物理像素，慢速移动时出现重复位置和单像素跳变。
- 灵动岛卫星按 1/480 秒固定子步推进，没有显示余量插值；144Hz 无法整除该步长，超过 480Hz 可能重复位姿。
- 灵动岛模糊的间隔使用 `Client()->PerfFrame()` 主循环计数，而非真实渲染帧计数。忙轮询时可能每次绘制都刷新，限制循环时可能跳过绘制；不能直接换算成固定的刷新率三分之一。
- Tee 设置页每帧先调用 `LoadingStats()` 再遍历皮肤统计任务状态，存在两次完整皮肤表扫描。

只读分析已有 `qm_perf_2026-09-16_23-47-35.log`：版本 3.6.1、Vulkan、上限 404 FPS、VSync 关闭。日志完整开始/结束，21,437 个帧样本合计 54.627 秒，整段 P50 2.475ms、P95 2.631ms、P99 4.106ms、最大 502.029ms；34 帧超过 16.67ms，5 帧超过 50ms。整段混合启动、加载与在线操作，不作为正常游玩或当前 3.8.x 的性能基线。最慢加载附近 `update_pump_network` 500.678ms；在线 `frame_render` 最大 65.068ms，尚无当前版本可比复现来完成进一步归因。

已检查主循环调度、菜单空闲节流、公共动画/滚动、卡片、HUD/灵动岛、皮肤、实时消息及后台完成路径。现有活动动画会解除菜单空闲节流。大消息首次 JSON 解析、新闻/赞助缓存同步写盘、小窗重复场景绘制仍是待实测的事件性或配置相关开销；本次不把它们认定为普遍动效不顺的根因。

## 实现与测试边界

- 公共 tween/解析弹簧使用完整有效时间；延迟边界只积分实际活动时间，固定时长队列顺序消耗剩余时间。拖拽边缘自动滚动仍限制交互步长，不补做切后台期间的输入位移。
- 滚轮过渡保留初次滚动曲线、每格距离、配置时长和边界，连续及反向输入继承当前速度；立即滚动与拖动语义保留。
- 卡片及默认/自定义折叠按钮始终保留小数几何，避免开始和停止动画时切换吸附方式；边框宽度保持物理像素对齐，边缘由现有抗锯齿绘制处理。
- 卫星改为欠阻尼解析求值，保留阻尼、轻回弹、反向连续和静止收尾。默认岛设计缩放 0.8 → 0.7，1080p 主体约 40.32px；跟随角色的计时环最小线宽仍为 1.0，不随岛缩小。
- 模糊允许每个新的绘制调用帧更新，同帧仍复用；分辨率、模糊参数和配色不变。在原先跳过刷新的调度模式中，GPU 提交会增加，尚未测量其成本。
- 设置页皮肤统计合并为一遍扫描，不增加跨帧缓存，不改变上传预算、任务优先级或完成结果读取条件。

先补回归测试代码，再实现。覆盖刷新率和时间分割、长帧、延迟、队列、滚动接续/反向/边界、运动小数几何、卫星反转/收尾、岛尺寸、模糊复用和皮肤状态计数。没有测试执行的红绿证据，也没有优化后 FPS、1% low 或视觉验收结果。

## 只读审查与收口

Findings：审查发现滚动曲线越界时的不可见速度可能被后续滚轮继承，现已在截断位置前将该速度归零，回归测试要求触底速度为零。卡片最初采用动静两态吸附，审查指出切态本身会跳变，且四处自定义折叠按钮没有同步状态；最终统一保留连续绘制几何，移除两态切换，所有折叠按钮共享相同路径。复核上述问题已解决，本轮没有剩余可操作 finding。

结论：本轮确认范围内的源码及配套测试代码完成，版本 3.8.0 → 3.8.1。尚不能据此声称全客户端已消除所有卡顿；当前版本的 GPU 时间、实时消息尖峰以及实际视觉效果需要独立实机采样。
